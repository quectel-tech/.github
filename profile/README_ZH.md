## 核心开发框架

移远通信核心开发框架为基于移远蜂窝 / 智能模块开发应用提供底层支撑，支持 C/C\+\+ 以及 Python 开发。

|框架名称|对应项目|
|---|---|
|Python 物联网框架|QuecPython|
|单片机‑模块交互 SDK|UniKnect|
|移远 Pi 软件开发工具包|Quectel Pi|

# 产品线

## 📶 蜂窝模块

> 4G LTE / 5G NR / Cat\.1 / NB‑IoT，面向工业、车载、安防等蜂窝联网场景

|代码仓库|说明|开发语言|
|---|---|---|
|`quectel‑cellular‑sdk`|蜂窝模块主机单片机 SDK，AT 指令驱动以及主机端示例|C|
|`quectel‑at‑examples`|蜂窝系列模块 AT 指令使用示例|C/Python|
|`quectel‑5g‑demos`|5G 高速数据、RMNet、QMI 应用演示代码|C|
|`quectel‑cat1‑nbiot‑samples`|Cat\.1 / NB‑IoT 低功耗典型场景示例代码|C|

## 🛰️ GNSS 定位模块

|代码仓库|说明|开发语言|
|---|---|---|
|`quectel‑gnss‑demos`|定位解析、NMEA 协议、RTK 差分演示代码|C|
|`quectel‑gnss‑host‑driver`|GNSS 模块单片机侧驱动|C|

## 📻 短距离无线

> Wi‑Fi / 蓝牙 / BLE 低功耗蓝牙
> 

|代码仓库|说明|开发语言|
|---|---|---|
|`quectel‑wifi‑ble‑sdk`|Wi‑Fi \& BLE 应用框架与外设演示工程|C|
|`quectel‑ble‑examples`|BLE 广播、连接、透传示例代码|C|

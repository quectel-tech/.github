### 🔄 如何更新本地仓库地址

如果您已 clone 了旧组织下的仓库，可执行以下命令将 remote 指向新地址：

```bash
# 进入仓库目录后
git remote set-url origin https://github.com/quectel-developer/<仓库名>.git

# 验证是否更新成功
git remote -v
```
